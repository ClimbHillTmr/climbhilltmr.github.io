## 页面设计与交互特点

- **温暖社论风格（Editorial Design）** — 延续暖米白（`#faf9f5`）与陶土橙（`#b36549`）配色，搭配衬线标题与舒适的正文阅读字号层次。
- **论文检索与一键引用** — 支持按研究领域筛选、关键词实时检索（快捷键 `/`）、DOI 直达、BibTeX 弹窗查看与一键复制。
- **清晰的 GitHub 入口体系** — 导航栏 `@ClimbHillTmr` 快捷入口、开源项目仓库标识（`ClimbHillTmr/rig-gateway`、`ClimbHillTmr/SubNano-HIL-MC`）与页脚根域名入口统一对齐至 `https://climbhilltmr.github.io/`。
- **零构建原生实现** — 纯原生 **HTML · CSS · JavaScript**，无第三方前端框架依赖，同时提供单文件离线预览版 `docs/preview.html`。
